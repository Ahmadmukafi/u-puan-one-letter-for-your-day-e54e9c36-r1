One letter, A to Z, standing for the word that describes the day.

> X

The hidden word behind the letter is "eXhausted" — the sharp, non-obvious initial of a day ground down to nothing. `main.ts` writes that single letter to `/output/entry.txt` (no trailing newline). Built for the [make.fun bounty](https://make.fun/c/u-puan-one-letter-for-your-day-e54e9c36).
